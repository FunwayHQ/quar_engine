Architecture

Based on ORB-SLAM3 (Campos et al., IEEE T-RO 2021)

Feature Detection

FAST-9 corners with NMS, ORB binary descriptors, Hamming distance matching with cross-check and ratio test.

Optical Flow

Lucas-Kanade pyramid tracker with gyro-compensated flow to isolate translation from rotation.

Pose Estimation

Essential matrix via 8-point + RANSAC, SVD decomposition, chirality check, and DLT triangulation.

Optimization

Levenberg-Marquardt bundle adjustment with Huber robust cost. Pose graph optimization for loop closure.

VIO Pipeline

IMU preintegration (Forster et al.), automatic scale estimation, gravity alignment, and Kalman filtering.

Scene Understanding

RANSAC plane fitting, horizontal/vertical classification, ray-plane hit testing for object placement.
